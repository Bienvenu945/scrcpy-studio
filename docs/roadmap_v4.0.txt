============================================================
1. VISION
============================================================

Scrcpy Studio est un lanceur graphique premium pour scrcpy.

Son objectif : rendre accessible toute la puissance de
scrcpy via une interface moderne, fluide et haut de gamme.

Principe directeur :

    Simple par défaut, complet sur demande,
    beau dans tous les cas.

L'interface adopte une esthétique "néon-bleu premium" :
fond noir profond, accents bleu néon et violet, cartes
denses aux bordures fines et lumineuses, animations
subtiles.

RÈGLE FONDAMENTALE :

    Aucune option de scrcpy ne doit être inaccessible
    via le GUI en mode PRO.

============================================================
8. MULTI-INSTANCES
============================================================

Chaque instance = configuration + appareil.

STRUCTURE :
    Instance {
        id: str (uuid)
        name: str
        settings: Settings
        current_profile: str
        adb_device: Device | None
        running: bool
        process: QProcess | None
    }

COMPORTEMENT :
    - Nouvelle instance : [+ New Instance]
    - Fermer : ✕ sur l'onglet
    - Basculer : clic sur l'onglet
    - Une seule instance tourne à la fois (par défaut)
    - Max 8 instances simultanées

PERSISTANCE :
    Liste d'instances dans config.json
